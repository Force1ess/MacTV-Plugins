# MacTV Plugins

[简体中文](README.zh-CN.md)

Install [Steam Big Picture](steam/README.md) from the official plugin source in [MacTV](https://github.com/Force1ess/MacTV).

The plugin catalog and packages are hosted directly in this Git repository. To develop a plugin, see the [SDK](sdk/README.md). Run `npm test` to check the packages and SDK.
